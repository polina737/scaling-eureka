Отчёт о проделанной работе  
Тема: Разработка бизнес-логики и интерфейса автомата по выдаче снеков

Цель работы: Изучить принципы проектирования пользовательского интерфейса и бизнес-логики для интерактивного автомата, освоить базовые возможности онлайн-редактора Figma.

Инструмент: Figma (онлайн-редактор интерфейсов)

Я определилась с задачей в проекте. Моя задача: написать бизнес-логику и нарисовать интерфейс экрана автомата в Figma.

При использовании автомата я рассматриваю два сценария:
1. Верное решение задачи и получение снека:
  - Автомат в режиме ожидания — на экране приветствие и кнопка «START».
  - Пользователь нажимает «START».
  - На экране появляется QR-код со ссылкой на Telegram-бот.
  - Пользователь сканирует QR-код, открывается бот.
  - Бот приветствует и предлагает выбрать уровень сложности задания, на экране появляется режим ожидания.
  - Пользователь выбирает уровень, бот присылает математическую задачу.
  - Пользователь вводит ответ.
  - Бот проверяет ответ, ответ верный
  - Бот отправляет сигнал на сервер автомата, тот выдаёт снек. На экране появляется сообщение «Молодец! Забирай вкусняшку!».
2. Неверное решение задачи:
  - Автомат в режиме ожидания — на экране приветствие и кнопка «START».
  - Пользователь нажимает «START».
  - На экране появляется QR-код со ссылкой на Telegram-бот.
  - Пользователь сканирует QR-код, открывается бот.
  - Бот приветствует и предлагает выбрать уровень сложности задания, на экране появляется режим ожидания.
  - Пользователь выбирает уровень, бот присылает математическую задачу.
  - Пользователь вводит ответ.
  - Бот проверяет ответ, ответ неверный
  - Бот отправляет сигнал на сервер автомата. На экране появляется сообщение о предложении попробовать еще раз.

Разработка интерфейса в Figma:
Для создания макетов был выбран онлайн-редактор Figma — бесплатный инструмент, работающий в браузере и специально предназначенный для проектирования интерфейсов.

Был создан фрейм под размер экрана автомата. На основе характеристик дисплея (3.5 дюйма) выбрано разрешение 480×320 пикселей.
